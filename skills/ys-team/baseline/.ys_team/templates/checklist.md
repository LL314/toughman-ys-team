# 交付清单模板

把本文件中的适用项复制到 verifier 卡的 `## 交付清单`。流程性待办交给 agent 原生 todo，不在这里打勾。

## 文档

- [ ] README / 用户文档已同步
- [ ] 方法论 / 规则 / skill 文案已同步
- [ ] 项目现实索引或约束地图已同步

## 验收

- [ ] 目的与验收证明已对齐，目的不是实现动作
- [ ] 预期来自需求、规格或独立样例；bug 修复有前后证据，或已写明无法复现的限制
- [ ] 复杂任务按可独立验收的完整行为拆分；不能独立验收时已注明依赖和统一验收点
- [ ] 保真度等级已声明
- [ ] Feedback Loop 可在 30 秒内复现，或 N/A 理由成立
- [ ] UI/交互类达到至少 L2
- [ ] L0/L1 降级理由已写明人工剩余项

## 状态与记忆

- [ ] `status.md` 只保留当前仪表盘和最近 5 条判断
- [ ] 任务过程、命令输出、QA 结论和发布证据已写入 spec / evidence
- [ ] 可复用经验已写入 `.ys_team/memory/`，或说明无需更新

## 发布

- [ ] 版本文件已同步
- [ ] 构建或打包验证已通过
- [ ] 发布 gate 已完成

## 项目本地 SOP

- [ ] 命中项目本地 SOP 时，已完成该 SOP 的结果责任项
- [ ] 如发现可复用失败模式，已写入 `.ys_team/memory/` 错题本
